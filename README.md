# Calendar
Requirements-driven calendar system designed using UML modeling and SQL, including use case, class, and sequence diagrams, along with a detailed Software Requirements Specification (SRS) to demonstrate software engineering best practices.

## Project Overview
The system supports calendar event creation, modification, deletion, and viewing. With role-based access control and validation rules to ensure data consistency and
system reliability.

## Key Contributions
- Analyzed functional and non-functional requirements and documented them in a detailed Software Requirements Specification (SRS).
- Designed system architecture using UML diagrams, including use case, class, and sequence diagrams.
- Modeled relational database structures and implemented SQL scripts to support event storage and retrieval.
- Defined system workflows for core operations such as load, store, and silent mode behaviors.

## Technologies & Tools
- UML modeling tools
- SQL (relational database design)
- Software Engineering methodologies
- Object-Oriented Design principles
